
# 🌍 AI Travel Planner (CrewAI + Gemini)

An intelligent multi-agent travel planning system built using **CrewAI** and **Google Gemini**, with a clean **Streamlit UI**.

---

## 🚀 Features

- 🧠 Multi-Agent System (CrewAI)
  - Travel Planner
  - Budget Analyst
  - Local Guide
  - Personalization Agent

- ✨ Gemini AI Integration (fast & cost-effective)

- 🎨 Interactive Streamlit Dashboard
- 📊 Budget Visualization (Pie Chart)
- 🧠 User Preference Memory (Session-based)
- 📋 Structured Travel Itinerary Output

---

## 🛠️ Tech Stack

- Python
- CrewAI
- Google Gemini (via CrewAI LLM)
- Streamlit
- Matplotlib

---

## ⚙️ Setup Instructions

### 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/ai-travel-planner.git
cd ai-travel-planner
````

---

### 2️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

### 3️⃣ Setup Environment Variables

Create a `.env` file in root:

```env
GOOGLE_API_KEY=your_gemini_api_key
```

Get your API key from:
👉 [https://makersuite.google.com/app/apikey](https://makersuite.google.com/app/apikey)

---

### 4️⃣ Run the App

```bash
streamlit run app.py
```

---

## 🧪 Example Usage

* Enter destination (e.g., Goa, Manali, Bali)
* Select days and budget
* Choose travel type (budget/luxury/family/solo)
* Add preferences (veg food, beaches, nightlife, etc.)
* Click **"Generate Travel Plan"**

---

## 📊 Output Includes

* Day-wise itinerary
* Budget breakdown
* Travel tips
* Personalized recommendations
* Visual budget chart

---

## 📌 Limitations

* No real-time booking APIs (flights/hotels)
* Uses AI-generated estimates
